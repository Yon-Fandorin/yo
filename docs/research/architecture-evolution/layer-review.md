# Layer-by-layer source reinspection

> Status: non-authoritative design review; 2026-10-05
>
> 기준 revision과 원본의 범위는 [source evidence](./evidence.md)를 따른다.

새 fresh-context 에이전트 3명과 주 에이전트가 비교표의 29개 레이어를 나눠,
인용 코드의 함수와 인접 호출부를 다시 읽었다. 기존 review verdict는 근거로 사용하지
않았다. 아래 표는 실제 확인 경로와 설계 판단이다. 모든 저장소의 모든 줄을 감사하거나
upstream을 실행한 결과가 아니며, 공개되지 않은 GUI/cloud 구현은 확인 범위에 넣지 않는다.

핵심 누락은 MCP startup/lifetime admission, transport/catalog bounds, 첫 DOM의
interactive request profile이었다. 이를 [통합 설계](./README.md)와
[도입·검증 기준](./implementation.md)에 반영했다. 조립의 cwd-bound services 분리와
package/eval evidence는 지나치게 짧았던 설명을 구체화했다. 단순화 때문에 의도적으로
보류한 기능은 아래에 이유를 남긴다. 세 담당이 수정본과 이 검토표까지 독립 재검토했고,
검토 범위에서 남은 material finding은 없다.
