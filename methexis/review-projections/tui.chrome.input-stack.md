## Translation

편집 가능한 TUI 셸은 정적 입력 크롬을 일시적인 작업 영역, 프롬프트, 호스트가 실제로 아는 메트릭, 폭에 맞춘 키 도움말과 표시 모드 순서로 배치해야 합니다. 작업 영역이 들어가는 높이라면 유휴와 활성 상태에서 같은 공간을 예약하여 Turn 상태가 바뀌어도 프롬프트가 움직이지 않게 합니다. 터미널이 너무 짧으면 선택적인 크롬 정보보다 프롬프트와 읽을 수 있는 최소 대화 기록을 보존합니다.

Turn이 활성 상태이면 완성된 입력 스택은 일반 `Esc`와 `Ctrl+C`를 모두 중단 수단으로 제공하고 두 키는 같은 중단 의도를 전달해야 합니다. 푸터가 들어가면 그곳에 표시하고, 아니면 장식 애니메이션보다 먼저 작업 행에 표시합니다. 높이나 폭 때문에 어느 행에도 두 표식을 함께 넣을 수 없으면 시각 안내는 생략할 수 있지만 두 입력 제스처의 동작은 그대로 유지해야 합니다.

입력 정책은 중단, 설정된 줄바꿈, 빈 프롬프트 종료 동작의 시맨틱 가용성을 제공해야 합니다. TUI는 하나의 공용 터미널 표기 소유자를 통해 Escape는 `Esc`, 제어 문자는 `^C`와 `^D` 같은 캐럿 표기, 그 밖의 수정 키는 `C-`, `M-`, `S-` 접두사로 나타냅니다. 유휴 `Esc`는 동작으로 광고하지 않습니다. GUI는 같은 시맨틱 동작을 플랫폼에 맞는 표식이나 아이콘으로 다르게 표현할 수 있습니다.

실제로 보이는 프롬프트 오버레이는 재배치 없이 예약된 작업 행과 인접 대화 셀을 사용할 수 있습니다. 일반 작업 행을 감추기 전에 오버레이가 들어가는지 판단해야 합니다. 오버레이 안내는 `Esc` 닫기와 `Ctrl+C` 중단을 노출해야 하며, `Esc`는 오버레이만 닫고 `Ctrl+C`는 오버레이 바인딩을 우회해 활성 Turn을 중단해야 합니다. 닫거나 패널 한 행도 들어가지 않으면 스냅샷이 아니라 현재 상태에서 작업 행을 복원합니다. 구체적인 오버레이 소유자가 없을 때 유휴 `Esc`는 미처리 상태이고, 유휴 `Ctrl+C`는 입력 지우기와 두 번 눌러 종료하는 별도 정책을 유지합니다.

상태 행에는 호스트나 런타임 소유자가 실제로 아는 값만 넣습니다. 알 수 없는 백엔드, 작업공간, 모델, 컨텍스트, Git 상태, 권한 값은 추측하지 않고 생략합니다. 상태는 우선순위가 명시된 좌우 타입 세그먼트로 조합하며, 셀 폭이 부족하면 개행하거나 자르거나 프레임을 실패시키지 않고 세그먼트 전체를 제거합니다.

프롬프트와 최소 대화 기록을 보존한 뒤 선택 행은 작업 행, 메트릭, 푸터 순으로 배정합니다. 활성 푸터 안에서는 중단 안내가 표시 모드, 줄바꿈 안내, 빈 프롬프트 종료 안내, 장식 작업 텍스트보다 오래 남아야 하고, 줄바꿈 안내는 종료 안내보다 오래 남는 편이 좋습니다. 이 계약은 정적 배치와 이벤트 기반 투영만 소유하며 애니메이션 프레임, 경과 시간, 시간 기반 다시 그리기, 설정 가능한 상태줄 조합, 추가 상태 데이터 소스는 후속 계약에서 다룹니다.
