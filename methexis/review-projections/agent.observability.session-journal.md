# Korean Review Projection

## Translation

# 영속 세션 관찰 저널

## 계약

하나의 순서가 보장된 영속 세션 저널이 세션 화면과 진단 이력을 재생하는 원본이어야 합니다. 저널은 백엔드 중립적인 세션·턴·활동 사건과, 그 사건에 연결된 백엔드별 통신 사건을 함께 기록해야 합니다. 백엔드 통신 봉투에는 백엔드 종류와 버전, 관찰 경계, 방향, 페이로드 스키마, 연산 상관관계가 들어가야 합니다. 요청, 응답, 알림, 서버가 시작한 요청, 재시도, 최종 결과를 서로 구분할 수 있어야 합니다.

의미는 수집할 때 확정해야 하며, 나중에 오래된 백엔드 통신 페이로드만 다시 해석해 의미를 복원해서는 안 됩니다. Request 진단을 위해 백엔드별 페이로드를 보존할 수 있지만, 알 수 없거나 지원하지 않는 페이로드는 다른 의미 기록의 재생을 막지 않는 명시적인 '관찰 불가'로 남겨야 합니다. 영속 저장 전에 민감정보를 제거해야 합니다. 자격 증명, 전체 환경 변수, 비공개 추론 값과 그 밖의 금지된 원시 값은 저널에 들어가면 안 되며, 해석에 영향을 주는 제거는 명시적으로 표현해야 합니다.

## 이유

안정적인 의미와 백엔드별 증거를 함께 수집하면 백엔드와 독립적인 이력을 유지하면서도 현재 Codex app-server 경계와 미래의 더 깊은 직접 모델 전송을 정확히 진단할 수 있습니다.
