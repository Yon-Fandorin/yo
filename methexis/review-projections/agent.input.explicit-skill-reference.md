# 명시적 스킬 참조

메뉴에서 선택한 `$name`은 실행 환경, 안정적인 스킬 식별자, 출처, 카탈로그 세대와 개별 항목 리비전을 가진 타입 참조가 됩니다. 입력과 Journal은 스킬을 순서 있는 컬렉션으로 저장하지만, 버전 1 정책은 0개 또는 1개만 허용합니다. 두 번째 선택은 기존 입력을 보존한 채 거절하며, 추후 검토된 정책으로 상한만 바꿀 수 있습니다.

카탈로그 탐색, 사용 가능성 판단, 로딩과 컨텍스트 조립은 실제 스킬 자산과 실행 능력을 소유한 환경이 담당합니다. 후보에는 본문 대신 식별자, 이름, 짧은 설명, 출처, 사용 정책, 상태·사유, 카탈로그 세대와 개별 리비전만 전달합니다. 같은 이름은 합치지 않고 출처와 함께 구분하며, 알려졌지만 사용할 수 없는 항목은 이유와 함께 비활성으로 표시합니다.

선택만으로 SKILL.md를 읽거나 실행하거나 지침을 주입하지 않습니다. 제출 승인 단계에서 모든 파일·스킬 참조를 먼저 검증하고, 선택된 정확한 항목 리비전을 검증한 동일 스냅샷에서 로딩해 검증과 사용 사이의 경쟁을 막습니다. 관련 없는 카탈로그 변경은 동일한 스킬을 무효화하지 않습니다.

승인과 거절은 제출 ID를 포함합니다. 승인은 그 스냅샷의 소유권 이전이며, 사용자가 대기 중 새 입력을 편집했다면 새 입력은 그대로 둡니다. 사라짐, 비활성화, 환경 불일치 또는 예산 초과는 전송을 거절하고 입력을 보존합니다. 같은 이름의 다른 스킬로 바꾸거나 일반 텍스트로 낮추거나 일부만 로딩하지 않습니다. 요청 비용에는 선택한 본문뿐 아니라 필수 보조 자료와 프레이밍도 포함하며 전체 카탈로그는 주입하지 않습니다.
