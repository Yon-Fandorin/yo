# 실행 워크스페이스 참조

메뉴에서 선택한 `@path`는 화면의 문자열과 별개로 실행 환경, 워크스페이스, 루트, 루트 상대 경로, 파일·디렉터리 종류를 가진 타입 참조가 됩니다. 여러 워크스페이스 참조는 입력 순서대로 한 요청에 담을 수 있습니다.

탐색과 최종 해석은 프론트엔드나 오케스트레이션 위치가 아니라 실제 워크스페이스를 소유한 실행 환경이 담당합니다. Git ignore와 exclude는 후보의 관련성만 정하며 권한 경계가 아닙니다. 숨김이지만 무시되지 않은 항목은 포함하고, Git 내부와 워크스페이스 밖으로 나가는 심볼릭 링크는 제외합니다. 불완전한 탐색이나 읽기 실패는 완전한 목록인 것처럼 숨기지 않고 상태로 알립니다.

선택 시 파일 본문을 읽거나 디렉터리를 재귀 첨부하지 않습니다. 제출 직전에는 실행 환경, 루트, 경로, 종류, 경로 containment와 권한을 다시 확인합니다. 파일 내용의 일반적인 수정은 경로 참조를 무효화하지 않지만 루트 매핑, 종류, 링크 대상, 경계 또는 권한 변화는 거절 사유입니다. 모든 참조가 통과하기 전에는 백엔드 전송이나 스킬 로딩을 시작하지 않습니다.

승인과 거절은 모두 제출 ID를 돌려줍니다. 승인은 정확히 그 입력 스냅샷의 소유권이 런타임으로 넘어가는 시점이며, 기다리는 동안 사용자가 새 내용을 편집했다면 새 입력은 지우지 않습니다. 거절도 입력과 타입 참조를 소비하지 않습니다. 승인된 구조적 의미는 Journal에도 구조적으로 남기며 나중에 `@path` 문자열만 보고 추측하지 않습니다.
