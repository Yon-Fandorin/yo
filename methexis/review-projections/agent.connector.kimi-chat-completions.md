## 이유

별도 dialect는 하나의 backend loop와 connector-neutral visible observation을 유지하면서 Kimi의 model-specific request, terminal, private-continuation grammar가 provider-neutral OpenAI Connector에 섞이는 것을 막습니다. 문서화된 동등 usage 위치만 명시적으로 허용하면 terminal evidence를 약화하지 않고 Kimi compatibility를 처리할 수 있습니다. Schema에 묶이고 숨겨지며 크기가 제한된 replay item을 사용하면 reasoning을 노출하거나 visible text만으로 exact continuation이 된다고 가장하지 않으면서 K3를 주력 지원 모델로 유지하고 두 exact K2.7 Code variant도 필요한 reasoning state를 보존할 수 있습니다. K2.6은 단순한 non-thinking fallback으로 남고, 검토되지 않은 다른 모든 profile은 자신의 exact overlay가 검토될 때까지 visible 상태로 유지합니다.
